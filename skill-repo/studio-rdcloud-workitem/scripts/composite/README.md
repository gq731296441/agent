# Scripts/Composite 复合脚本目录

本目录用于编排多步的**组合能力**（如先查后改、先查后导出等）。

## 功能定位

通过顺序调用 `atomic/` 下脚本或封装为独立入口完成复杂业务场景：
- 先查询后更新
- 先查询后导出
- 创建并通知并关联
- 批量操作

## 当前状态

当前目录可为空；具体编排见 flows/ 或后续补充。

## 组合能力示例

```python
# 示例：查询并导出
# 1. 调用 query_work_item.py 查询
# 2. 调用 export_work_item.py 导出结果

# 示例：创建并关联
# 1. 调用 create_work_item.py 创建
# 2. 调用 relate_work_item.py 建立关联
```

## 结果展示约束

**默认不得总结、省略或改写脚本返回结果**；仅当用户语义明确要求"总结/汇总/精简"时，才可在完整结果后追加总结。

## 工具约束

- **必须**使用本技能已有 `scripts/` 脚本执行研发云工作项能力
- **禁止**使用 write、edit、web-search、web_fetch 等处理本业务或替代脚本
- **禁止**新建 Python 脚本
