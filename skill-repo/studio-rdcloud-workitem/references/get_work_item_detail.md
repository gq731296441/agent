# 工作项详情 · 脚本入参说明


> **工具约束（必遵）**：须通过本技能已有 `scripts/` 脚本执行研发云工作项能力；**禁止**使用 write、edit、web-search、web_fetch 等处理本业务或替代脚本；**禁止**新建 Python 脚本。

对应脚本：`scripts/atomic/get_work_item_detail.py`。按工作项标识查询详情并格式化输出；**支持多个标识，以英文逗号分隔**。

执行规则：不做执行前确认；脚本执行完成后，先展示「本次语义解析结果」（工作项标识、工作区等），再展示详情结果。

结果展示约束（与心智提示一致，**必遵**）：面向用户时须**完整**展示脚本标准输出，**禁止**总结、合并、缩写、截断、省略或改写；**禁止**将多条详情揉成一段摘要；**禁止**去掉 Markdown 链接与结构。仅当用户明确要求「总结/汇总/精简」时，才可在**完整贴出脚本输出之后**再追加归纳。

## 命令行调用

```bash
python scripts/atomic/get_work_item_detail.py --work-item-id PLM-12345
python scripts/atomic/get_work_item_detail.py --work-item-id PLM-12345,PLM-12346
python scripts/atomic/get_work_item_detail.py --work-item-id PLM-12345
```

## 参数说明（仅字面值）

| 参数 | 必填 | 说明 |
|------|------|------|
| **--work-item-id** | 是 | 工作项标识，多个以英文逗号分隔，如 PLM-12345,PLM-12346 |
| **--user-input, --userInput** | 否 | **用户的原始输入**，必须是用户真实、完整的一句话，用于工作区/类型/字段解析的上下文与日志 |

## 执行流程（总分总）

参数解析 → 参数调整（解析工作区，支持多 ID）→ 调用查询 API（一次请求多 ID）→ 提取全部条目 → 逐条格式化为详情 Markdown（多条以 `---` 分隔）→ 追加心智提示（未查到时的建议）。

## 心智提示

未查到该工作项时，结果后会追加：检查标识是否完整、是否有权限、是否需在其他工作区查询。
