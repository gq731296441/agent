# Studio 研发云工作项技能

研发云工作项技能（studio-rdcloud-workitem）是一个用于与中兴研发云（RDC）工作项系统交互的 AI 技能包。支持工作项的创建、更新、查询、关联、导出、统计等全生命周期管理。

## 版本信息

- **技能名称**: studio-rdcloud-workitem
- **版本**: 1.2.8
- **别名**: rdc、研发云、R&D Cloud

## 目录结构

```
studio-rdcloud-workitem/
├── assets/              # 配置文件目录
├── docs/                # 用户文档和设计文档
├── logs/                # 日志文件目录
├── references/          # 技术参考文档
├── scripts/             # 脚本代码目录
│   ├── atomic/          # 原子脚本（核心功能）
│   ├── common/          # 公共模块和工具类
│   ├── composite/       # 复合脚本（组合功能）
│   ├── createCustom/    # 定制创建脚本
│   └── tests/           # 测试脚本
├── SKILL.md             # 技能定义文件
└── README.md            # 本文件
```

## 各目录说明

| 目录 | 说明 | 详细内容 |
|------|------|----------|
| **assets/** | 配置文件 | 存放技能运行时所需的配置文件，如 `config.json`（工作区、API 配置等） |
| **docs/** | 用户文档 | 面向最终用户的使用指南、设计文档、流程图等 |
| **logs/** | 日志目录（本地开发回退） | 仅在本地开发（无 `/workspace`）时使用。沙箱容器内 skill 为只读挂载（`/mnt/skills/<id>:ro`），运行日志改写至 `/workspace/.skill-logs/{skill_id}/`；Excel 导出产物写至 `/workspace/exports/{skill_id}/` |
| **references/** | 技术参考 | 面向开发者和维护者的技术文档，描述各脚本的入参、出参、使用方式 |
| **scripts/atomic/** | 原子脚本 | 核心功能脚本，每个脚本完成单一明确的功能（创建、更新、查询等） |
| **scripts/common/** | 公共模块 | 工具类、辅助函数、配置解析、认证、日志等公共能力 |
| **scripts/composite/** | 复合脚本 | 组合多个原子能力的脚本（如有） |
| **scripts/createCustom/** | 定制创建 | 针对特定工作项类型的定制创建逻辑 |
| **scripts/tests/** | 测试脚本 | 单元测试、集成测试脚本 |

## 核心功能

### 1. 创建工作项
- 支持类型：任务、缺陷、用户故事、变更请求、问题单、待办事项
- 不支持：原始需求、外场故障、测试用例、测试计划、测试记录
- 支持创建后关联、邮件/消息通知

### 2. 更新工作项
- 支持更新字段值、状态
- 支持批量更新（多个工作项）
- 支持更新后关联、邮件/消息通知

### 3. 查询工作项
- **通用查询**：按条件查询全工作区的工作项
- **与我相关**：查询指派给我、我创建的、我编辑的、我关注的、我的待办
- **超期查询**：查询超期的工作项
- **根据链接/查询名查询**：按预设查询链接或查询名查询
- **关联查询**：查询关联的工作项
- **树查询**：查询层级结构

### 4. 工作项详情
- 查询单个或多个工作项的完整详情

### 5. 关联工作项
- 建立工作项之间的关联关系（子级、父级、相关、前置、后续等）

### 6. 导出工作项
- 将查询结果导出为 Excel 文件

### 7. 统计工作项
- 对工作项数据进行统计（count、sum、avg、min、max）

### 8. 工作项评论
- 查询评论、添加评论、回复评论

## 快速开始

### 用户使用说明

1. **触发技能**：在对话中提及 "rdc"、"研发云"、"R&D Cloud" 等关键词
2. **表达意图**：使用自然语言描述您的需求
3. **查看结果**：系统会执行对应操作并返回结果

### 示例话术

```
# 创建
在 rdc 中创建 任务，标题：完成登录接口开发
rdc 新建 缺陷，标题：首页白屏，优先级：P0

# 更新
将 PLM-12345 的状态改为进行中
更新 PLM-12345,PLM-12346 的指派给为张三

# 查询
在 rdc 中查询 状态：进行中 的任务
rdc 我的任务，前 20 条
查询我超期的缺陷

# 关联
将 PLM-100 与 PLM-200 建立关联，关联类型：相关

# 导出
导出 PLM 工作区的任务为 Excel
```

## 开发与维护

### 编码规范
- 所有 Python 文件使用 UTF-8 编码
- 遵循项目现有的代码风格和命名规范
- 新增功能需配套更新文档和测试

### 添加新功能
1. 在 `scripts/atomic/` 下创建新的原子脚本
2. 在 `references/` 下创建对应的技术参考文档
3. 在 `docs/` 下创建或更新用户指导文档
4. 更新 `SKILL.md` 中的功能映射表

### 测试
测试脚本位于 `scripts/tests/` 目录下，包括：
- `atomic/` - 原子脚本测试
- `common/` - 公共模块测试
