# 脚本与错误处理

本文档以**错误处理**为主。CLI 子命令、参数以 **`python3 {baseDir}/scripts/main.py <子命令> --help`** 为准；速查与分组见 [cli_subcommands.md](cli_subcommands.md)。意图与步骤见 [workflow.md](workflow.md)、[SKILL.md](../SKILL.md)。

---

## 错误处理

### 通用错误（所有子技能适用）

脚本以**非 0 退出**或 **stdout/stderr 中含 `{"error":"..."}`** 时视为失败，须将 **error** 原文展示给用户。

| 场景 | 处理方式 |
|------|----------|
| 脚本以非 0 退出或输出含 `error` 键 | 展示 `error` 中的提示信息，建议重试或登录 Web 邮箱处理 |
| 无法解析 stderr | 提示「邮件服务暂时不可用，请稍后重试。」 |
| **查找邮件返回 `beyond_half_year: true`**（结束日期超过半年） | 向用户说明：「半年前的邮件请使用历史邮件查询」 |
| 认证/登录异常 | 提示需要重新登录或联系管理员 |

#### 脚本可能抛出的典型错误文案（应原样展示给用户）

| 场景 | 示例 error 文案 |
|------|-----------------|
| UDS 不可用 | 无法连接到 UDS 客户端，请确认 UDS 桌面云客户端正在运行。 |
| zmail 登录失败 | zmail UACTokenLogin 请求失败 (HTTP 4xx/5xx): ... |
| zmail 网络错误 | zmail 请求网络错误: ... |
| zmail 登录未成功 | zmail UACTokenLogin 未成功: （服务端返回的 M/C 消息） |
| 响应缺 token | zmail 响应中未包含 D.T (zmail token) |
| 搜索失败 | zmail SysSearchMailExpert 请求失败 (HTTP ...): ... |
| 获取邮件失败 | zmail SysGetMailContext 请求失败 (HTTP ...): ... |
| 响应格式异常 | zmail 响应中 D 不是对象或为空 |
| 其它未预期异常 | Unexpected error: ... |

### 收件箱 / 总结 / 草稿箱 / 新建邮件

| 场景 | 处理方式 |
|------|----------|
| **未展示或未获用户确认即调用 send/create-draft** | 默认须展示并等待用户确认。**例外**：若用户明确表示「直接发」「不用确认」等希望无需确认即发送，可展示后直接调用；否则必须先展示邮件信息并等待用户回复「确认发送」「发送」「发吧」等。见 [send.md](send.md) 步骤 3、步骤 4。 |
| **发送时某群组无权限**（如 error 含「用户没有权限使用邮件组」） | **强硬要求**：不得自行改选其他群组；直接提示「xx 群组没有权限」或原文展示 error，由用户决定是否更换收件人 |
| **展示 search-users 结果** | **强硬要求**：必须严格按照 [search-users](search-users.md) 返回的数据展示；**优先姓名+工号**（如「谢飞武（0668001367）」），**无姓名或工号时再用邮箱 E**；禁止臆断、猜测、编造。若有密送关键字，同样按 search-users 返回进行展示与同名确认，bcc/bcc_group 需在最终「邮件发送成功」提示中展示 |
| 上下文无草稿列表但用户说「第 N 封」 | 提示用户先说「查看草稿箱」获取列表 |
| 序号超出范围 | 提示「草稿箱共 N 封邮件，请选择 1~N」 |
| 时间解析失败 | 提示用户用清晰的时间表述，如「明天 9:00」「2026-02-12 14:00」；见 [time.md](time.md)。**「定时」「定时邮件」不算用户提到具体发送时间**，仅说定时一律立即发送；若用户说了可识别的时间表述但无法解析为具体时刻，须询问用户确认具体发送时间 |
| 必填参数缺失 | 向用户询问缺失的参数（收件人、发送时间；**用户提到具体发送时间（create-draft）时主题必填**，未提到具体时间（send）时标题和内容可选） |

### 搜索 / 查看 / 回复

| 场景 | 处理方式 |
|------|----------|
| 搜索成功但 count=0 | 提示「没有找到与'{keyword}'相关的邮件，请尝试其他关键词。」 |
| 查看时找不到对应邮件 | 提示用户重新搜索或确认序号/标题 |
| 回复时上下文中无邮件 ID | 提示「当前没有查看的邮件」，建议先搜索或查看一封邮件 |
| 回复时用户未提供内容 | 提示「请填写邮件内容」 |
| 回复脚本返回 status: false | 展示 `error` 中的失败信息（已含 Web 邮箱提示），建议检查网络或重试 |
