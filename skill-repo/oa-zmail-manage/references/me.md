## 「我」的解析（收件人/发件人为「我/自己」时）

当用户表述中**收件人指当前用户本人**时（包括说「我」「自己」「我的邮箱」等；收件人、抄送人、密送任一角色为「我」时同理），须先获取当前用户完整信息并用该信息代表「我」，**不得将「我」作为关键字传给任何搜索或发送接口**。

- **触发表述**：如「给我发邮件」「给自己发一封」「往我的企业邮箱发送」「发到我的邮箱」「在 X 点给我发邮件」「明天发到我的企业邮箱」等（提到具体时间则为预约发送，否则为立即发送）。
- **必须执行**：先运行 `python3 {baseDir}/scripts/main.py my-info`（见下「调用与出参」），将输出中的 **`user`**（含 UNO、N、E、T，与 search-users 用户项一致）作为「我」的代表；**传 `--to`/`--cc`/`--bcc` 时仅能为邮箱，请使用 `user.E`**；展示仍可用姓名+工号。无需再对「我」调用 search-users。
- **禁止**：不得将「我」「自己」「我的企业邮箱」等直接作为关键字传给 `search-users` 或其它接口；若 `my-info` 失败或返回为空，应提示用户检查环境或改为指定具体收件人。收件人、抄送人、群组均须来自 **search-users** 确认结果或 **my-info** 返回的当前用户信息。

### 调用 my-info

```bash
python3 {baseDir}/scripts/main.py my-info
```

#### 入参

无（无位置参数与可选参数）。

#### 出参（stdout JSON）

**成功**：

```json
{"status": true, "user": {"UNO": "0668001367", "N": "张三", "E": "zhangsan@zte.com.cn", "T": "技术部", "D": null, "P": "", "Y": "", "C": "", "F": null}}
```

- **UNO**：工号；**N**：姓名；**E**：邮箱；**T**：部门。其余字段可能为空，以实际返回为准；`user` 结构与 search-users 用户项一致，可直接用于代表「我」。

**失败**：stderr：`{"status": false, "error": "无法获取当前用户工号"}` 等，退出码非 0。
