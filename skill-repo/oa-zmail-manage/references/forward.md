# 邮件转发（参考）

本参考描述**转发当前查看的邮件**的完整流程：获取邮件 ID、先检查邮件是否支持转发、收件人解析（与新建邮件相同，走 search-users）、**转发前展示并等待用户确认**、用户明确发送后再调用转发脚本。转发时默认携带原邮件附件；用户明确不要附件时在调用脚本时传 `--with-attachments false`。原始邮件区域与回复相同（含 From/To/Cc/Date/Subject 及原文内容）。

**强制要求（不可跳过）**：**必须先展示转发预览（标题、收件人、抄送、密送、转发正文），等用户明确确认（如回复「确认发送」「发送」）后才能调用转发脚本。** 即使用户在一次消息中同时给出了转发对象和转发内容，也**不得直接发送**，必须先把转发预览展示给用户，等待用户说「确认发送」或「发送」后再执行；**严禁在未展示、未获用户确认的情况下直接调用转发脚本。**

**收件人展示规则**（与发邮件、回复一致）：**优先使用姓名+工号，没有时再使用邮件地址**。有 N、UNO 时用「姓名（工号）」；无时用邮箱地址。

## 模型执行口径（必须遵守）

- 模型在处理“转发”意图时，**第一条工具调用必须是** `check-forward`（在已拿到邮件 ID 的前提下）。
- 若 `check-forward` 返回 `status=false`，模型**立即结束流程**，只向用户输出「该邮件不支持转发」，不得继续做收件人解析、预览展示或发送调用。
- 仅当 `check-forward` 返回 `status=true`，模型才进入后续步骤（search-users、预览、确认、forward）。
- 除非用户明确确认发送，模型不得调用 `forward`。

## 触发场景

以下情况**会触发转发**：

- "把这封邮件**转发**给张三"
- "**转发**当前邮件给 A、B"
- "把这封邮件**转发给我的邮箱**，内容加一句：请查收"
- "**转发**给谢飞武"

## 前置条件

1. **从上下文获取当前邮件 ID**：
   - 用户刚通过「查看」看过某封邮件，该邮件的 ID 应从对话上下文中取得。
   - **若上下文中没有可用的邮件 ID**：提示「当前没有查看的邮件」，建议用户先搜索或查看一封邮件后再转发，流程结束。

2. **先检查是否支持转发（必须）**：
   - 调用 `python3 {baseDir}/scripts/main.py check-forward "<邮件ID>"`。
   - 若返回 `{"status": false, "error": "该邮件不支持转发"}`，则**直接提示用户该邮件不支持转发并结束流程**，不再执行后续步骤（不做收件人解析、不展示预览、不调用 forward）。
   - 仅当返回 `{"status": true}` 时，才继续后续流程。

3. **从用户输入获取收件人**：
   - 收件人解析逻辑**完全复用** [search-users.md](search-users.md) 与 [send.md](send.md) 的流程（包含同名确认、多群组选择、no_match 处理等），确认后通过 `--to`/`--cc`/`--bcc` 传入。
   - 收件人为「我」时，须先调用 `main.py my-info` 获取当前用户信息，用返回的 `user` 代表「我」。

4. **从用户输入获取转发正文**（可选）：
   - 用户可附加转发说明，如「内容加一句：请查收」；未提供时转发正文为空，仅转发原文。

## 转发前展示与确认（必须执行）

**在调用转发脚本之前**，必须完成以下步骤，**不得在未展示、未获用户确认的情况下直接发送**。

1. **检查是否支持转发（必须先做）**  
   调用 `main.py check-forward "<邮件ID>"`：若 `status=false`，直接提示「该邮件不支持转发」并结束；仅 `status=true` 时继续后续步骤。

2. **解析收件人**  
   收件人、抄送人、密送人**不能同时为空**，至少填一项。按 [search-users.md](search-users.md) 执行：对收件人/抄送人/密送人调用 `main.py search-users`，处理 `keywords_with_multiple`（同名/多群组需用户确认）、`no_match_keys`（未匹配提示）。确认后得到邮箱列表，调用 `forward` 时传入 `--to`/`--cc`/`--bcc`。

3. **获取原邮件标题**  
   通过 `view` 或 `reply-brief` 获取原邮件标题，用于组装转发预览的标题（格式：`转发: 原标题`）。

4. **组装转发预览信息**  
   - **标题**：`转发: ` + 原标题（不可修改）
   - **收件人**（来自 search-users 确认结果，展示规则：姓名（工号）或邮箱）
   - **抄送**（仅当 `cc` 中列表非空时展示本行）
   - **密送**（仅当 `bcc` 中列表非空时展示本行）
   - **转发正文**（用户填写的可选内容；无则留空）
   - **是否携带原邮件附件**（**必须**：当根据上下文可判定原邮件有附件时，预览中须单独展示一行，写清本次转发是**带附件**还是**不带附件**）：未提及附件时默认**带附件**（对应脚本省略 `--with-attachments` 或 `--with-attachments true`）；用户明确不要附件时为**不带附件**（对应 `--with-attachments false`）。
   - 说明：原文内容将一并附在下方。

5. **向用户展示**  
   以简洁格式展示给用户。

6. **等待用户回应**  
   - 若用户回复「**确认发送**」「**发送**」「**发吧**」等**明确发送意图**：则进入下一步调用转发脚本。
   - 若用户要求**修改转发正文**：更新后**重新展示**预览，再次等待确认。
   - 若用户要求**修改收件人/抄送/密送**：重新走 search-users 流程，确认后再次展示预览。
   - 若原邮件有附件且用户要求**改为带附件/不带附件**：更新**是否携带原邮件附件**一行后重新展示预览，再次等待确认。
   - 仅当**明确识别到发送意图**后，才可调用转发脚本。

### 转发预览展示格式示例

```
**转发邮件预览**

**标题**：转发: 季度会议邀请
**收件人**：张三（0668000001）
**是否携带原邮件附件**：带附件（默认；原邮件有附件时本行必填）
**转发正文**：
请查收。

（原文内容将一并附在下方）

请回复「**确认发送**」以发送，或告诉我需要修改的**转发正文**或**收件人**。
```

（原邮件**无**附件时，预览中可不展示「是否携带原邮件附件」一行。）

## 调用转发脚本

**仅当用户已明确表示发送后**，在技能目录下执行：

（必须先检查）

```bash
python3 {baseDir}/scripts/main.py check-forward "<邮件ID>"
```

- 返回 `{"status": false, "error": "该邮件不支持转发"}`：直接结束，不再调用 `forward`。
- 返回 `{"status": true}`：继续执行 `forward`。

```bash
python3 {baseDir}/scripts/main.py forward "<邮件ID>" "<转发正文>" [--to "<邮箱1,邮箱2>"] [--cc ...] [--bcc ...] [--with-attachments true|false]
```

- **{baseDir}**：当前 skill 目录的绝对路径。
- **邮件ID**（必填）：当前查看的邮件 ID，从上下文中获取。
- **转发正文**（可选）：用户填写的转发说明；无则传空字符串 `""` 或省略该位置参数。
- **--to / --cc / --bcc**：逗号分隔邮箱；至少一项非空。与 send 一致，见 [cli-to-cc-bcc.md](cli-to-cc-bcc.md)。
- **--with-attachments**（可选）：true \| false，默认 true；不带附件时传 false。

无转发正文时示例：

```bash
python3 {baseDir}/scripts/main.py forward "<邮件ID>" "" --to "xiefeiwu@zte.com.cn"
```

## 根据返回值处理

- **成功**：退出码 0，stdout 为 `{"status": true, "mid": "<邮件ID>"}`。`mid` 仅用于后续操作/链路追踪，**不要展示给用户**；回复用户时说明已转发，并附 Web 邮箱链接即可。

- **失败**：退出码非 0，stderr 为 `{"status": false, "error": "异常信息"}`。将 **error** 原文展示给用户，建议检查网络或重试。参见 [scripts_and_errors.md](scripts_and_errors.md)。

### 输出格式模板（成功）

```
邮件已转发，更多信息请登录 [zMail Web 邮箱](https://zmail.zte.com.cn)。
```

## 错误处理

- **上下文无邮件 ID**：提示「当前没有查看的邮件」，建议用户先搜索或查看一封邮件后再转发。
- **邮件不支持转发**：先执行 `check-forward`；若返回 `status=false`，直接提示「该邮件不支持转发」，不再执行后续步骤。
- **收件人未确认**：存在同名用户或多群组时，必须展示列表让用户选择，禁止自行选定。
- **未提供 to/cc/bcc 或邮箱非法**：脚本返回错误，将 error 原文展示给用户。
- 其他错误：参见 [scripts_and_errors.md](scripts_and_errors.md)。
