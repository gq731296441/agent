# 文件夹（参考）

本参考描述**查看文件夹列表**与**移动邮件到指定箱体/文件夹**的完整流程。

---

## 一、文件夹列表

### 触发场景

以下情况**会触发文件夹列表**：

- "**查看**文件夹"
- "**我的**文件夹"
- "**文件夹**列表"
- "有哪些文件夹"

### 调用脚本

在技能目录下执行：

```bash
python3 {baseDir}/scripts/main.py folder-list
```

#### 入参

- **{baseDir}**：当前 skill 目录的绝对路径。
- 无位置参数与可选参数。

#### 出参（stdout JSON）

**成功**：stdout 为 JSON，`folders` 为可展示的文件夹列表（仅 EF='Y'），`folder` 为层级路径（如 `自定义/工作/子文件夹`）。

| 字段 | 类型 | 说明 |
|------|------|------|
| folders | array | 文件夹列表 |
| count | number | 文件夹数量 |

`folders` 每项：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 文件夹 ID |
| folder | string | 文件夹完整路径（含父子层级，如 `工作/项目A`） |

```json
{"folders": [{"id": "100", "folder": "工作/项目A"}, {"id": "101", "folder": "个人"}], "count": 2}
```

**失败**：退出码非 0，stderr 为 `{"error": "具体错误信息"}`，须将 **error** 原文展示给用户。参见 [scripts_and_errors.md](scripts_and_errors.md)。

### 示例（文件夹列表）

```
用户：查看我的文件夹

AI：您当前有 5 个文件夹：

| 序号 | 文件夹路径 |
| ---- | ---------- |
| 1 | 已发送 |
| 2 | 已删除 |
| 3 | 自定义/项目邮件 |
| 4 | 自定义/工作 |
| 5 | 自定义/归档 |
```

```
用户：文件夹列表

AI：共有 3 个文件夹：

| 序号 | 文件夹路径 |
| ---- | ---------- |
| 1 | 已发送 |
| 2 | 已删除 |
| 3 | 自定义/工作 |
```

### 展示规范（文件夹列表）

- **count 为 0**：提示「暂无文件夹」。
- **count > 0**：以表格展示 `序号` 与 `文件夹路径`，便于用户查看。
- **失败时**：原文展示脚本返回的 `error`。

## 二、删除邮件（delete-mails）

> 说明：收件箱、草稿箱、发件箱、自定义文件夹中的“删除”或者“移动到已删除（回收站）”须用 **`delete-mails`**，**禁止**用 `move-emails` 代替删除；该删除操作**不是永久删除**，可以通过恢复操作恢复。
> 限制：历史邮件/归档邮件**不能删除**；命中时须明确提示「历史邮件/归档邮件不能删除」。

### 触发场景

以下情况**会触发删除邮件**（走 `delete-mails`，勿拼 `move-emails --mailbox-type deleted`）：

- "删除这封邮件" / "删掉第 N 封"（已取得邮件 ID）
- "移到**已删除（回收站）**"
- "删除发件箱邮件"（按 ID）

### 调用脚本

```bash
python3 {baseDir}/scripts/main.py delete-mails --email-id <邮件ID，多个用逗号分隔>
```

#### 入参

| 参数 | 必填 | 说明 |
|------|------|------|
| `--email-id` | 是 | 邮件 ID，多个用逗号分隔 |

#### 出参（stdout JSON）

与移动邮件成功/失败结构一致（`status`、`message`、`success_count`、`fail_count` 等）。

### 展示规范（删除邮件）

- **成功**：直接展示返回的 `message` 信息；并在结果后追加：
  - `---`
  - `关联操作：`
  - `恢复邮件（恢复邮件）`
- **失败**：原文展示 `error`；若为部分成功则同时展示失败原因（`errors`）。

## 三、移动邮件（move-emails）

**仅用于**移动到收件箱、垃圾邮件或自定义文件夹；**不包含**移入已删除（删除请用上一节 `delete-mails`）。

### 触发场景

以下情况**会触发移动邮件**：

- "把**这封**邮件移到收件箱/垃圾邮件"
- "把邮件**移动**到 xxx 文件夹"
- "移到**垃圾邮件**"
- "移到**收件箱**"

### 调用脚本

在技能目录下执行：

```bash
python3 {baseDir}/scripts/main.py move-emails --email-id <邮件ID，多个用逗号分隔> --mailbox-type <箱体类型> [--folder <文件夹名称或ID>]
```

#### 入参

| 参数 | 必填 | 说明 |
|------|------|------|
| `--email-id` | 是 | 邮件 ID，多个用逗号分隔 |
| `--mailbox-type` | 是 | 目标箱体类型：`inbox`（收件箱）、`spam`（垃圾邮件）、`folder`（指定文件夹）。**不支持把邮件移动到 `outbox`**，**不支持** `deleted`（删除须用 `delete-mails`）。移入自定义文件夹须 `folder` 并配合 `--folder` |
| `--folder` | 条件 | 文件夹名称或 ID。**传入时以该文件夹为目标**（解析规则见实现）。纯数字时按 ID 匹配，否则按名称匹配 |

#### 出参（stdout JSON）

**成功**：stdout 返回 `{"status": true, "message": "已成功将N封邮件移动到xxx", "success_count": N, "fail_count": 0}`，可直接展示 message 给用户。部分成功时含 `errors` 数组。

**失败**：stdout 返回 `{"status": false, "error": "错误信息"}`。若包含 `folder_data`，可一并展示可用文件夹列表供用户选择。

### 示例（移动邮件）

```
用户：把邮件移到「工作」文件夹

AI：已成功将邮件移动到工作文件夹。
```

```
用户：把邮件移到「项目邮件」文件夹

AI：名称「项目邮件」的文件夹不存在。您当前可用的文件夹如下：

| 序号 | 文件夹路径 |
| ---- | ---------- |
| 1 | 已发送 |
| 2 | 已删除 |
| 3 | 自定义/工作 |
```

### 展示规范（移动邮件）

- **成功**：直接展示返回的 `message` 信息。
- **失败**：原文展示 `error`；若返回 `folder_data`，可表格展示可用文件夹，引导用户重新选择。
- **强约束**：当用户要求“删除已删除（回收站）中的邮件”时，明确告知“已删除邮件不支持再次删除”。

## 四、恢复邮件（仅“已删除”箱体）

### 触发场景

以下情况会触发“恢复邮件”：

- "恢复邮件"
- "恢复已删除的邮件"
- "把回收站里的邮件恢复"
- "从已删除恢复这几封邮件"

### 关键规则（强约束）

- **仅“已删除/回收站”下的邮件可以恢复**：不在“已删除”箱体的邮件一律视为失败并提示原因。
- **支持多个邮件 ID**：多个用逗号分隔。

### 调用脚本

在技能目录下执行：

```bash
python3 {baseDir}/scripts/main.py recover-mails --email-id <邮件ID，多个用逗号分隔>
```

#### 入参

| 参数 | 必填 | 说明 |
|------|------|------|
| `--email-id` | 是 | 邮件 ID，多个用逗号分隔 |

#### 出参（stdout JSON）

- **成功**：`{"status": true, "message": "已成功恢复N封邮件", "success_count": N, "fail_count": 0}`
- **部分成功**：`status=true` 且包含 `errors`
- **失败**：`{"status": false, "error": "错误信息", "success_count": 0, "fail_count": N}`

### 示例（恢复邮件）

```
用户：把回收站里的这两封邮件恢复一下

AI：已成功恢复2封邮件。
```

### 展示规范（恢复邮件）

- **成功**：直接展示返回的 `message` 信息。
- **失败**：原文展示 `error`；若为部分成功则同时展示失败原因（`errors`）。
