# 空间管理子技能

## 1. 适用范围

- 搜索空间、创建空间、重命名空间
- 我管理的空间、个人空间（单人管理员空间）
- 查看成员/管理员、添加成员、删除成员
- 设置/取消管理员（由对话层调用脚本内接口，无独立 CLI）
- 选人桥按姓名/工号查询员工

### 1.1 调用禁令（与总入口 `SKILL.md` 同步）

- **禁止**在调用本子技能所列脚本（含下文示例命令）时，自行在 shell 命令中追加 `2>&1`、`&>`、`> ... 2>&1` 等会把 **stderr 合并进 stdout**（或与 stdout 写入同一流）的重定向。约定：**业务结果走 stdout**（如 `--json-output`）、**日志与提示走 stderr**；合并后会破坏 JSON/结构化解析与排障。若需保存输出或日志，应使用脚本自身提供的参数或约定方式，而不是改 shell 重定向。

## 2. 脚本映射

- `scripts/space_member_setting.py`

## 3. 常用触发词（分类）

- **空间检索**：搜索空间、找空间、XX 空间、空间关键词
- **我管理/个人空间**：我管理的空间、我负责的空间、个人空间、我的个人空间
- **创建/改名**：新建空间、创建空间、空间改名、重命名空间
- **成员**：加人、添加成员、删除成员、踢人、谁在空间里、成员列表
- **管理员**：设置管理员、取消管理员、谁是管理员
- **选人桥**：查工号、查姓名、按姓名搜、按工号搜、公司员工

## 4. 意图识别与命令路由（核心）

### 4.1 路由优先级（一句话多意图时）

1. **选人桥/查人**（出现“工号、姓名、查谁、员工、通讯录式查询”且**未**明确绑定到“某空间加人”）→ `--employee`
2. **创建空间**（新建/创建空间）→ `--create-space`
3. **重命名空间**（改名/重命名 + 已能定位 spaceId）→ `--update-space-name`
4. **我管理的空间** → `--list-managed-spaces`
5. **个人空间** → `--find-personal-space`
6. **成员增删**（需已解析 `spaceId` + 工号）→ `--add-member` / `--remove-member`
7. **默认**：按关键词搜索空间 → `<空间关键词>`

若用户先说“把张三加到测试空间”，这是**成员添加**，应先通过 `<关键词>` 搜索并选定空间，再执行 `--add-member`（见 4.3）。

### 4.2 意图 -> 命令决策表

| 用户意图 | 必要参数 | 首选命令 | 说明 |
|---------|----------|----------|------|
| 按名搜索空间 | 关键词 | `space_member_setting.py <关键词>` | 结果中可看成员/管理员 |
| 我管理的空间 | 无 | `--list-managed-spaces` | 带链接列表 |
| 个人空间 | 无 | `--find-personal-space` | 仅一人为管理员的空间 |
| 创建空间 | 名称；描述可选 | `--create-space "名称" ["描述"]` | 名称/描述须来自用户当前输入 |
| 重命名空间 | `spaceId` + 新名称 | `--update-space-name <spaceId> "新名称"` | 无单独「仅改描述」CLI |
| 选人桥 | 姓名或关键词或工号 | `--employee "<姓名或工号>"` | 占位符须换成真实值 |
| 添加成员 | `spaceId` + 工号 | `--add-member <spaceId> <工号>` | 需先确定目标空间 |
| 删除成员 | `spaceId` + 工号 | `--remove-member <spaceId> <工号>` | 同上 |
| 设置/取消管理员 | `spaceId`、成员、角色 | 对话层调脚本内接口 | 见 6. 约束 |

### 4.3 参数提取规则

- **空间定位**：用户只说空间名时，先用 `<关键词>` 搜索；选定 `spaceId` 后再做成员/管理员类操作。
- **我是成员的空间**：本脚本无「一键列出全部我参与空间」；用用户可能记得的名称/关键词搜索。
- **工号格式**：添加/删除成员参数为**工号**；若用户只给姓名，应先 `--employee` 或选人桥结果再确认工号。
- **创建/改名文案**：示例中的名称、描述**禁止照抄**，必须来自当前对话。

### 4.4 澄清问题模板（缺参时必须询问）

- 添加/删除成员但不知目标空间：  
  “要操作的是哪个空间？可提供空间名关键词，或给我空间 ID。”
- 只知姓名不知工号：  
  “请提供对方工号，或我先按姓名在选人桥查询后您确认人选。”
- 重命名但无 spaceId：  
  “请先搜索并确认要改名的空间，或提供 spaceId。”
- 创建空间缺名称：  
  “请提供新空间名称（可选：一句话描述）。”

## 5. 命令模板

```bash
# 按关键词搜索空间（可选：在结果中查看成员/管理员）
python3 scripts/space_member_setting.py <空间关键词>

# 我管理的空间
python3 scripts/space_member_setting.py --list-managed-spaces

# 个人空间（仅自己为唯一管理员）
python3 scripts/space_member_setting.py --find-personal-space

# 创建空间（描述可选）
python3 scripts/space_member_setting.py --create-space "空间名称" ["空间描述"]

# 修改空间名称
python3 scripts/space_member_setting.py --update-space-name <spaceId> "新名称"

# 选人桥（姓名或工号，勿照抄占位符）
python3 scripts/space_member_setting.py --employee "<姓名或工号>"

# 添加/删除成员（需已确定 spaceId）
python3 scripts/space_member_setting.py --add-member <spaceId> <工号>
python3 scripts/space_member_setting.py --remove-member <spaceId> <工号>
```

## 6. 约束与澄清

- 无单独「仅修改空间描述」CLI；描述可在创建空间时传入；查看空间信息时会展示描述。
- 设置/取消管理员须保证空间**至少保留一名管理员**；管理员总数上限以平台为准（常见为 15）；**不允许**取消当前登录用户自己的管理员身份（以脚本约定为准）。
- 选人桥或姓名解析出现重名时，列出候选并要求用户选定工号后再执行加人/邮件等操作。
