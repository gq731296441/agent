# 字段规格说明

## 必需字段定义（wx 13 列）

组件清单数据位于 **【软件结构】sheet**，需包含以下 13 个必需列（表头验证，缺失则终止处理）。

### 1. 层次 (level)
- **类型**: 整数
- **描述**: 表示部件在层级结构中的深度，顶层为 0
- **约束**:
  - 必填
  - 第一行（索引 0）必须为 0（否则标记警告）
  - 子节点的层次与前序层次差值不能大于 1（否则标记"层次断层"）
- **示例**: `0`, `1`, `2`

### 2. 部件类别 (component_category)
- **类型**: 枚举
- **描述**: 部件的类型分类
- **可选值**:
  - `系统` - 完整产品或系统（第一级部件）
  - `软件` - 纯软件产品（第一级部件）
  - `软件子系统` - 软件的子系统
  - `软件模块` - 软件模块
  - `组件` - 通用组件
  - `外部第三方组件` - 外部采购的第三方组件
- **约束**: 必填，必须是上述值之一；区分大小写，必须完全匹配

### 3. 中文名称 (zh_name)
- **类型**: 字符串
- **描述**: 部件的中文名称
- **约束**:
  - 部件编号为空时必填
  - 首位不能是符号
- **示例**: `身份认证服务`

### 4. 英文名称 (en_name)
- **类型**: 字符串
- **描述**: 部件的英文名称
- **约束**:
  - 部件编号为空时必填
  - 首位不能是符号，且不能包含中文
- **示例**: `Authentication Service`

### 5. 英文代号 (en_code)
- **类型**: 字符串
- **描述**: 部件的英文代码标识
- **约束**:
  - 部件编号为空时必填
  - 首位不能是符号，且不能包含中文
- **示例**: `AUTH_SVC`

### 6. 组件版本 (component_version)
- **类型**: 字符串
- **描述**: 组件的版本号
- **约束**: 可选
- **示例**: `1.0.0`, `2.1.3`, `2024.03`

### 7. 组件资产类型 (asset_type)
- **类型**: 字符串
- **描述**: 资产分类
- **约束**: 可选
- **示例**: `软件资产`, `固件`, `驱动`

### 8. 服务制品类型 (artifact_type)
- **类型**: 字符串
- **描述**: 制品类型（如 war 包、jar 包等）
- **约束**: 可选
- **示例**: `war`, `jar`, `dll`, `exe`

### 9. 服务等级 (service_level)
- **类型**: 字符串
- **描述**: 服务等级标识
- **约束**: 可选
- **示例**: `L1`, `L2`, `L3`, `紧急`

### 10. 部件编号 (part_number)
- **类型**: 字符串
- **描述**: 部件的唯一标识编号
- **约束**:
  - 外部第三方组件必填（缺失标记错误）
  - 常规部件若填写，则会通过 PDM 校验/查询；为空时须填写中文名称/英文名称/英文代号
- **示例**: `130000249711`

### 11. 组件功能说明 (function_description)
- **类型**: 字符串
- **描述**: 组件功能的详细说明
- **约束**: 可选

### 12. 组件接口说明 (interface_description)
- **类型**: 字符串
- **描述**: 组件接口的描述信息
- **约束**: 可选

### 13. 备注 (remarks)
- **类型**: 字符串
- **描述**: 其他补充说明
- **约束**: 可选

## 最新模板扩展列（addDir 校验使用）

`validate` 的 addDir 部分需要最新模板的以下列（`db_and_path_check.py` 中的 `required_columns`）：

| 列名 | 说明 |
|------|------|
| `代码库/目录` | 组件的代码库名 + 路径，可含多个（逗号/换行/中文逗号分隔） |
| `是否核心组件/模块` | 是否为核心组件（是/否） |
| `组件对应的测试代码目录` | 测试代码目录 |
| `组件对应的UT代码目录` | UT 代码目录 |
| `组件对应的FT代码目录` | FT 代码目录 |
| `是否航天级组件` | 是否航天级组件 |
| `组件/模块代码量统计专用分支` | 代码量统计专用分支 |

缺失这些列时格式检查提示"未使用最新模板"。

**注意**：这 13+7 列是不同的校验对象——13 列是 wx 规则引擎的表头验证必需列，
扩展列是 addDir 格式检查所需的最新模板列。一份标准模板同时包含两者。

## query 查询结果字段

`query` 生成的查询结果报告字段（`generate_query_report` 的 `output_fields`）：

| 字段 | 说明 |
|------|------|
| `序号` | 全局唯一序号（跨源行递增，用于 backfill 精确选择） |
| `源行号` | 原始 Excel 行号 |
| `中文名称` / `英文名称` / `英文代号` | 查询条件（原样回显） |
| `部件编号` | 查询到的部件编号 |
| `版本` | 部件版本 |
| `生命周期状态` | 生命周期状态（如"审批完成"） |
| `部件类型` | 部件类型 |
| `所属产品` | 所属产品型号 |
| `产品编号` | productNo（多编号筛选依据） |
| `产品` | 产品名（多编号筛选依据） |
| `项目` | 项目名（多编号筛选依据） |
| `工作组类1` / `工作组类2` / `工作组类3` | 工作组类编号 |
| `查询策略` | 实际使用的查询策略（多条件组合/单条件） |

**多匹配语义**：同一源行可能查询到多个候选（不同 `序号`、不同 `部件编号`），
回填时通过 `--result-ids` 指定 `序号` 精确选择；冲突时可按第一级部件基准（产品/项目）自动筛选。

## 数据规范

### 总体要求
- 文件名：建议使用中英文混合，不超过 255 字符
- 工作表名：建议使用描述性名称，不超过 31 字符（Excel 限制）
- 数据编码：使用 UTF-8 编码保存 Excel 文件

### 层次关系
- 树形结构：0 层为根节点，每层递增 1
- 不要求连续：可以 0, 2, 3（表示跳过了第 1 层）——但前序层次差值 >1 会标记"断层"警告
- 父子关系：通过层次和排列顺序隐式定义

### 部件编号规范
- 唯一性：在整个系统中唯一
- 外部组件：通常使用供应商提供的编号（两段式如 `0013-0004`，三段式如 `0202-0000-0829`）

## API 验证字段映射

### 部件详情 API（PDM GBOM）
| Excel 字段 | API 字段别名 |
|-----------|-------------|
| 部件编号 | PART_NO |
| 中文名称 | NAME_CN, nameCn, name |
| 英文名称 | NAME_EN, nameEn |
| 英文代号 | EN_CODE, engCode |
| 部件类别 | PART_TYPE, partType, opsTypeIdName |

### 第三方组件 API（iComp）
| Excel 字段 | API 字段别名（接口1） | API 字段别名（接口2） |
|-----------|---------------------|---------------------|
| 部件编号 | externalId | compId/compCode |
| 中文名称/英文名称 | name | compName |
| 部件状态 | statusName | availableStatus |
| 部件类别 | opsTypeIdName | compTypeName |

### PDM 查询接口（query，/v1/pdm/query_part）
| 查询结果字段 | API 字段 |
|-------------|----------|
| 部件编号 | partNo / PART_NO |
| 版本 | version / VERSION |

| 部件类型 | partType / PART_TYPE |
| 所属产品 | productModel / PRODUCT_MODEL |
| 产品编号 | productNo / PRODUCT_NO |

| 项目 | project / PROJECT / projectName |
| 工作组类1/2/3 | team1/team2/team3 / TEAM1/TEAM2/TEAM3 |

## 字段长度限制（建议）
| 字段 | 最大长度 |
|------|----------|
| 中文名称 | 200 |
| 英文名称 | 200 |
| 英文代号 | 50 |
| 部件编号 | 100 |
| 组件功能说明 | 500 |
| 组件接口说明 | 500 |
| 备注 | 500 |

## 特殊字符限制
- 避免使用控制字符（ASCII 0-31）
- 避免使用 Excel 保留字符：`* ? [ ] :`
- 换行符：如果单元格需要换行，使用 `\n` 表示
